# 浏览器的页面循环系统

## 宏任务和微任务

1. 页面线程所有执行的任务都来自于消息队列，消息队列是"先进先出"的，消息队列的任务也称为宏任务
2. 如果遇到高优先级的任务，会放到当前宏任务下的微任务中，当前宏任务的主要功能完成后，先执行宏任务中的微任务

## 事件循环和消息队列

1. 消息队列是一种数据结构，可以存放要执行的任务，消息队列是"先进先出"的
2. 渲染主线程的任务都从消息队列中获取，其他线程添加新任务进消息队列尾部，渲染主线程从消息队列头部中读取任务并执行
3. 通过消息队列实现了线程之间的通信，
4. 渲染进程的IO线程可以接受其他进程的消息，然后添加到时间队列中
