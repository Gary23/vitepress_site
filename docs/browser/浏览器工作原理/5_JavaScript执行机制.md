# JavaScript执行机制

## JavaScript 代码的执行流程

一段js代码在执行之前需要被js引擎编译，编译完成后进入执行阶段

![js的执行流程图](/browser/649c6e3b5509ffd40e13ce9c91b3d91e.webp)

1. 编译阶段

   - 代码经过编译后，会生成两部分内容：**执行上下文和可执行代码**

   - 执行上下文存在一个**变量环境对象**，对象中保存了**变量提升的内容**

    ![js编译阶段](/browser/20241014110545.png)

2. 执行阶段

   - js引擎开始执行“可执行代码”，按照顺序一行行的执行
